# AI for Left Ventricular Analysis in Echocardiography

Series hub for SSP-MAEFNet, LV-SAM++, and EchoST-SAM.

Intended URL: https://lvyupku.github.io/echo-lv/

The hub and all three paper pages are standalone static HTML. Keep the four folders as siblings in the GitHub Pages repository. No package installation or build is required. Figures and materials are referenced from the original paper folders to keep one copy of every resource. Original diagrams are reproduced without cropping or redrawing.

The shared navigation uses `assets/research-family.css` in each folder. The hub uses the existing paper-page stylesheet plus `assets/hub.css`. All content and links remain usable without JavaScript; JavaScript adds figure enlargement and citation copying.

Release: 20261017-v1. The visible EchoST-SAM slide link is versioned to avoid serving an older cached PDF.
