# EchoST-SAM project page

Public URL: https://lvyupku.github.io/EchoST-SAM/

This standalone static page is published by the existing GitHub Pages site. It has no front matter, build step, external fonts, JavaScript framework, or dependency on changes to the parent Jekyll theme.

- `index.html`: paper content, result tables, metadata, resource links, and citation.
- `assets/style.css`: responsive layout using the parent AcademicPages typography and palette.
- `assets/main.js`: progressive enhancement for the figure viewer, citation copying, and section navigation.
- `assets/*.webp`: lossless conversions of the camera-ready paper figures.
- `assets/EchoST-SAM-paper.pdf`: supplied camera-ready manuscript.
- `assets/EchoST-SAM-slides.pdf`: 16:9 English presentation, 17 main slides and 7 backup slides.
- `assets/echostsam.bib`: citation; update both this file and the inline citation when proceedings metadata become available.

Source of scientific content: the supplied IVCNZ 2026 camera-ready manuscript, `conference_101719.tex`. The full and spatial variants are deliberately distinguished. The page states the study-specific split, additional annotations, reference ED/ES indices, metric definitions, single-run scope, and the Dice/temporal-consistency trade-off.

Figures open directly when JavaScript is disabled. The full result tables, all text, and PDF downloads do not require JavaScript. No code repository or dataset release is implied by the resource links; CAMUS links to the original dataset site.

The page uses a conventional paper-project structure (title, authors, resources, methods, evidence, citation); all page code was written for this project.
